# ランキング記録スキル (record-rankings)

このスキルは、ユーザーから提示された「小説家になろう」および「カクヨム」のランキング情報を受け取り、[rankings_manual.json](../../../rankings_manual.json) へ手動記録を追加して [data.js](../../../data.js) を再生成するまでの標準手順を定めたものです。

---

## 関連ファイル

- [config.json](../../../config.json): 作品タイトルと `ncode`（作品識別子）の対応定義
- [rankings_manual.json](../../../rankings_manual.json): 手動ランキング記録の格納先（各 `ncode` ごとの配列）
- [scripts/update_data.py](../../../scripts/update_data.py): データを再集計し `data.js` を生成するスクリプト
- [data.js](../../../data.js): Webフロントエンドが読み込む集計済みJavaScriptファイル

---

## データフォーマット仕様

`rankings_manual.json` 内の各作品の配列要素は以下のオブジェクト形式です。

```json
{
  "date": "YYYY-MM-DD",
  "label": "サービス名 種別 ジャンル(条件)",
  "rank": 70,
  "note": "更新時間帯や変動推移"
}
```

### 1. `label` の命名規則

#### 小説家になろう
- フォーマット: `なろう {期間/種別} {ジャンル名}({条件})`
- 期間/種別の例: `日間`, `週間`, `月間`, `四半期`, `年間`, `累計`, `注目度`
- ジャンル・条件の例:
  - `なろう 週間 ローファンタジー(すべて)`
  - `なろう 週間 ローファンタジー(連載中)`
  - `なろう 月間 ローファンタジー(連載中)`
  - `なろう 日間 ローファンタジー(連載中)`
  - `なろう 日間 ローファンタジー(すべて)`
  - `なろう 日間 総合(連載中)`
  - `なろう 注目度(すべて)`
  - `なろう 注目度(連載中)`
  - `なろう 注目度(完結済)`
  - `なろう 週間 現実世界(完結済)`

#### カクヨム
- フォーマット: `カクヨム {期間} {ジャンル名}`
- 例:
  - `カクヨム 週間 総合`
  - `カクヨム 週間 現代ファンタジー`
  - `カクヨム 週間 異世界ファンタジー`
  - `カクヨム 週間 ラブコメ`
  - `カクヨム 日間 現代ファンタジー`

### 2. `note` の命名規則
- **なろう**: 更新時間帯を記録（例: `"04-07時更新"`, `"11-12時更新"`, `"18-19時更新"`）
- **カクヨム**:
  - 前回からの変動がある場合: `"1274位→710位"` のように記載
  - 初ランクイン時: `"ランクイン"`
  - 変動記載が不要な場合: `""`（空文字列）

### 3. 並び順（ソート規則）
- 原則として `date` の降順（新しい日付が上）。
- 同一日の場合:
  - カクヨムの記録を先頭にするか、時間帯が遅い順（`18-19時更新` → `11-12時更新` → `04-07時更新`）に並べる。

## 実行手順（ワークフロー）

### ステップ 1: 作品（ncode）の特定
提示された小説タイトル・短縮タイトルから [config.json](../../../config.json) を検索し、対象の `ncode`（例: `n8135mt`, `n2175mw`, `n2286mu` 等）を特定します。

### ステップ 2: 既存エントリの確認
[rankings_manual.json](../../../rankings_manual.json) の対象 `ncode` の直近の記録を確認し、既存のラベル命名規則や並び順に合わせます。

### ステップ 3: `rankings_manual.json` の編集
各作品の配列へ新しいランキングエントリを適切な位置に挿入します。

### ステップ 4: JSON 構文の検証
文法エラー（カンマの過不足など）がないことを検証します。
```pwsh
python -c "import json; json.load(open('rankings_manual.json', encoding='utf-8')); print('JSON OK')"
```

### ステップ 5: 集計スクリプトの実行
集計スクリプトを実行し、`data.js` を再生成します。
```pwsh
python scripts/update_data.py
```
実行後、各作品の処理が `OK: {ncode}` となり、最後に `Wrote data.js with XX books.` と出力されることを確認します。

### ステップ 6: 変更の確認
`git status` および `git diff rankings_manual.json` で変更内容が期待通り反映されているか確認します。
```pwsh
git status -s
git diff rankings_manual.json
```

### ステップ 7: ユーザーへの報告
ユーザー指示のルールに従い、新規追加したランキングの内容と、事実に基づいた実行報告を行います。
