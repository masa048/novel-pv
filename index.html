本棚 PVモニタ 設定＆公開ガイド

1. 自分の作品を追加・変更する方法

リポジトリ直下の config.json を開いて、ご自身の作品のなろうNコード (ncode) とカクヨム作品ID (kakuyomuId) を編集・追加してください。 

{
  "books": [
    {
      "ncode": "n1234ab", // なろうの作品URLにあるNコード (例: n1234ab)
      "kakuyomuId": "1681692786028123456", // カクヨムのURLにある作品ID
      "title": "作品の正式タイトル",
      "shortTitle": "本棚に表示する短縮タイトル",
      "status": "ongoing", // "ongoing" (連載中) または "done" (完結)
      "genre": "女性向け", // "女性向け", "男性向け", "歴史", "ファンタジー" 等
      "order": 1, // 本棚の並び順
      "cover": "covers/my_cover.jpg", // 書影画像 (なしでも美しい和風装丁になります)
      "tags": ["異世界", "ざまぁ", "溺愛"],
      "mood": "作品の雰囲気・キャッチコピー"
    }
  ]
}

2. GitHub Pages の公開手順

  1. 本フォルダの内容をご自身の GitHub リポジトリ（例: novel-pv）にプッシュします。
  2. GitHubリポジトリの Settings > Pages を開きます。
  3. Build and deployment の Source で Deploy from a branch を選択します。
  4. Branch で main ブランチ、フォルダは / (root) を選んで Save を押します。
  5. 数分で https://<ユーザー名>.github.io/<リポジトリ名>/ でWebサイトが世界に公開されます！

3. 1時間ごとの自動取得 (GitHub Actions)

.github/workflows/update-pv.yml が設定されているため、GitHubにプッシュするだけで、GitHubのサーバーが1時間に1回自動で最新のPVを取得し、サイトを自動更新します。

今すぐ手動で更新したいときは、GitHubリポジトリの Actions タブ > Update Novel PV > Run workflow を押すと約1分で最新データが反映されます。
